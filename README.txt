MY GARAGE — version 1

INSTALL: Upload index.html, manifest.json, sw.js, icon-192.png and icon-512.png to a static HTTPS host (such as GitHub Pages). Keep them in the same folder. Open the resulting website in Safari on your iPhone, tap Share > Add to Home Screen > Open as Web App > Add. The app can work offline after the service worker caches the files successfully. You can also test index.html in a desktop browser, but local-file storage is browser dependent.

START: Add a vehicle and its current odometer. Log each repair with a consistent service name. Under Maintenance, set your own time and/or mileage intervals using the same service names. The dashboard shows due within 500 miles or 30 days, and overdue/due when an interval is reached. No reminder can be calculated without a matching record. Update your odometer regularly. Brake replacement should be based on inspection and manufacturer limits, not a fixed interval.

PRIVACY: All entered data stays in the app's local browser storage. No account, backend or automatic cloud sync. Export a JSON backup in Garage regularly and before switching phones or clearing data. Import replaces all records; export first. Deleting a vehicle also deletes its service and reminder records. No background notifications or automatic mileage readings in this version.
